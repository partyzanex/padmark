# Padmark — правки по дизайну

Пункты 1–7 — из прошлого пакета: что уже сделано, пропустить. Пункты 8–10 — новые.

Порядок: сначала то, что не сделано из 1–2, затем 8–10, затем остальное. После пунктов 1–2 и после пунктов 8–10 сделать скриншоты затронутых экранов во всех трёх темах и показать, прежде чем двигаться дальше.

Бэкенд не трогать, кроме того, что прямо сказано ниже.

## 1. Баланс форм — главное

Проблема: у ссылки и файла правая панель намного выше левой карточки, форма выглядит перекошенной.

Правило для всех форм — создание и редактирование заметки, ссылки, файла и изображения:

- **Колонки одной высоты.** Контейнер `display: flex; flex-wrap: wrap; gap: 20px; align-items: stretch`. Левая карточка `flex: 999 1 560px`, панель `flex: 1 1 300px`.
- **Левая карточка** — `display: flex; flex-direction: column`. Растягиваемая часть `flex: 1`, нижняя строка карточки прижата к низу.
- **Панель** — `display: flex; flex-direction: column`. Блок с главной кнопкой `margin-top: auto`, над ним разделитель. Кнопка стоит на одной линии с низом левой карточки.

Что внутри левой карточки (смотреть `screens/Link.html`, `screens/FileUp.html`, `screens/Main.html`):

- **Ссылка.**
  - Поле адреса — textarea на 3 строки: моноширинный 13px, перенос по символам, чтобы длинный URL был виден целиком. Под ним slug.
  - Ниже, на всю оставшуюся высоту, блок «Preview» на фоне `--sunken`, обновляется сразу:
    - короткая ссылка — моноширинный 20px, окончание цветом акцента;
    - строка про режим: «shows the destination first, then continues to» или «redirects to»;
    - домен крупно и полный адрес мелко;
    - чипы выбранных настроек: доступ, срок, «Burns after the first click», если включено.
- **Файл.** Зона загрузки `flex: 1`, минимум 220px. Выбранный файл показывается внутри зоны по центру: иконка, имя, размер, кнопки «Replace» и «Remove». Ниже slug, внизу строка «Your file link».
- **Заметка.** Редактор `flex: 1`, минимум 380px.
- **Экраны редактирования** ссылки и файла устроены так же. У ссылки тоже блок превью; у файла вместо зоны загрузки — тот же блок с файлом, без Replace и Remove, с пометкой «Name and content are fixed».

## 2. Правая панель

- **Доступ** — компактный список в одной рамке (скругление 10px) вместо трёх больших карточек.
  - Строка ~48px: radio, название 13px/600, описание 12px приглушённым цветом. Выбранная строка — фон `--accent-soft`.
  - Заголовок: «Who can read», «Who can follow» или «Who can download».
- **Если пользователь не вошёл,** Login required и Owner only не прятать, а показывать неактивными со строкой «Sign in to restrict access» (ссылка на вход). Сейчас остаётся радиокнопка из одного пункта.
- **Переключатели** — без цветных квадратиков с иконками: название 13px/600, подпись 12px, сам переключатель 40×24.
- **Ширина панели** не меньше 300px, чтобы названия помещались в одну строку.
- **Сгорание называется одинаково:** «Burn after reading», «Burn after first click», «Burn after first download». Сейчас у файла «Delete after first download».
- **Срок жизни ссылки:** готовые варианты плюс «Custom…». Для своего срока — число и единица (minutes / hours / days), а не секунды. Перевод в секунды — на фронтенде, API не менять.
- **Edit code** — поле с кнопкой генерации и подписью «Lets you edit or delete the {note|link|file} later».
- **На экранах редактирования:**
  - «Delete» отделить от «Save»: ниже, после разделителя, с подтверждением. У заметки тоже нужна «Delete note».
  - Неизменяемое — slug, сгорание ссылки после создания — показывать текстом со значком замка, а не полем ввода или выключенным переключателем.

## 3. Шапка и футер — одинаковые на всех страницах

- **Десктоп:** логотип · вкладки Note / Short link / File / Image · API · GitHub · тема (три кнопки) · «Sign in» или аватар.
  - Вкладки File и Image есть на всех страницах (если загрузка только после входа — вкладка ведёт на вход).
  - Админка и смена пароля — та же шапка, а не отдельный вариант.
  - На страницах просмотра вместо вкладок кнопка «New», как сейчас.
- **Мобильный:** справа всегда тема и меню. После входа вместо иконки меню — аватар, открывающий то же меню. «+» на страницах просмотра оставить.
- **Футер:** одна подпись везде — «Padmark — notes, links & files».

## 4. Тексты и мелочи

- **404:** «Paste not found» → «Not found»; «Create new paste» → «New note».
- **Reveal:** «One-time document» → «One-time note».
- **Число просмотров:** «1 views» → «1 view».
- **После публикации** одинаковый набор ссылок на всех экранах: «Write another note · Shorten a link · Upload a file · Upload an image».
- **Заголовки в тексте заметки:** h1 из Markdown 24px, h2 20px — меньше названия заметки, чтобы не было двух одинаковых заголовков подряд.
- **Плашка edit code в тёмных темах:** вместо сплошной коричневой заливки — рамка 1px `--warn` и лёгкий фон.

## 5. Страница ссылки в режиме «show destination first»

- Главная кнопка «Continue to {домен} →».
- Если ссылка сгорает после первого клика — предупреждение, как на reveal: «This link works once. Continuing uses it up.»

## 6. Мобильные

- **Edit code в одну строку:** без разрядки между буквами, кнопки Hide и Copy не должны переносить код.
- **Опасные кнопки:** «Delete file», «Delete link» и «Sign out» не ставить вплотную под главной кнопкой.
- **Админка:** вкладка показывает только свой раздел. Password — раздел внутри админки, с её шапкой.
- **Просмотр заметки:** без карточки с рамкой — текст прямо на фоне, отступ 16px. Строка «On this page» закреплена сверху при прокрутке.
- **Вход:** убрать «Back to Padmark», она разрывается на две строки.
- **Сводка в Settings у ссылки** показывает значение («expires in 2 min»), а не режим («custom, in seconds»).

## 7. Первый запуск (Create admin account)

- **Токен:** в поле — «Bootstrap token», пояснение «Value of PADMARK_BOOTSTRAP_TOKEN on the server» под полем. Справа в поле отступ под иконку глаза — сейчас текст уходит под неё.
- **Требования к паролю** — под полем (лучше списком, где каждое требование отмечается при вводе), не в placeholder.
- **Код из приложения.** Если после создания есть шаг подключения кода, сказать об этом в подзаголовке: «Step 1 of 2 — next you'll connect an authenticator app».
- **«Sign in» в шапке** скрыть, пока админ не создан.

## 8. Загрузка изображения — новое (`screens/ImageUp.html`, `screens/MobileImageUp.html`)

- **В шапку форм** добавить вкладку «Image» после File.
- **Каркас** — как у формы файла и по правилу пункта 1: карточка слева, панель справа, одной высоты.
- **Слева:**
  - зона загрузки «Drop an image here, paste it, or browse»: перетаскивание, выбор файла и вставка из буфера (Ctrl+V);
  - после выбора картинка показывается внутри зоны целиком (вписана), под ней имя, размер в пикселях, вес, формат и кнопки «Replace» и «Remove»;
  - поле «Description · optional» — подпись к картинке, идёт в `alt` на странице просмотра;
  - slug; внизу строка «Your image link».
- **Справа:**
  - «Who can view» — те же три уровня доступа;
  - «Expires» — пресеты и «Custom…»;
  - «Burn after first view»;
  - «Remove location data» — убрать GPS и данные камеры. **Только если сервер это умеет;** иначе не показывать;
  - Edit code, кнопка «Upload image».
- **Форматы и лимит:** PNG, JPEG, WebP, GIF. Лимит — тот же, что у файлов на сервере (в макете 1 MiB).
- **После загрузки** — экран «Your image is live», как у файла, с маленьким превью картинки.
- **Мобильный:** как форма файла — карточка, внизу закреплены «Settings» и «Upload image».

## 9. Просмотр изображения — новое (`screens/Image.html`, `screens/MobileImage.html`)

Картинка — главное на странице. Вся информация — одной узкой полосой над ней.

- **Полоса над картинкой:**
  - слева название (Source Serif 4, 20px) и строка мета: размер в пикселях, вес, формат, дата, просмотры, срок, доступ (моноширинный 12px);
  - справа «Copy link», «Embed ▾», «Edit», «Download». «Embed» открывает выпадающий блок с переключателем Link / Markdown / HTML, полем и кнопкой копирования. В Markdown и HTML подставлять прямую ссылку на файл картинки и описание как `alt`.
- **Область картинки:**
  - по ширине — почти весь экран: внешние отступы 8–20px, а не контейнер 1200px; по высоте — всё, что осталось под шапкой и полосой;
  - фон `--sunken`, рамка 1px, скругление 12px;
  - картинка: `max-width: 100%`, `max-height` — высота области, `width: auto; height: auto`, по центру. Если картинка меньше области — показывается в натуральную величину, не растягивается. Если больше — вписывается целиком.
- **Плашки в правом нижнем углу:**
  - масштаб: «100%» или «Fit · 38%» (`clientWidth / naturalWidth`, пересчитывать при загрузке и изменении размера окна);
  - кнопка «100%» — только если картинка не влезла. Показывает её в натуральную величину прямо на странице, область прокручивается (`overflow: auto`). Повторное нажатие — «Fit to screen»;
  - «Original» — открывает исходный файл в новой вкладке.
- **Клик по картинке** открывает исходный файл в новой вкладке (курсор `zoom-in`).
- **Под картинкой** — описание одной строкой по центру.
- **Мобильный:** картинка во всю ширину сразу под шапкой, нажатие открывает исходник. Ниже название, описание, мета, «Download» на всю ширину и три кнопки «Copy link», «Embed», «Edit». «Embed» раскрывает тот же блок под кнопками.
- **Если картинка сгорает после просмотра,** сначала показывать экран-предупреждение, как у одноразовой заметки (reveal), и только потом картинку.

## 10. Оглавление «On this page» — новое (`screens/Note.html`, `screens/NoteTocAll.html`)

Проблема: в большом документе с длинными заголовками оглавление вылезает за экран, появляется полоса прокрутки и всё выглядит плохо.

- **Колонка:** 260px (минимум 220), `position: sticky; top: 24px; align-self: flex-start`.
- **Список:** `max-height: calc(100vh - 140px); overflow-y: auto`. Полосу прокрутки скрыть (`scrollbar-width: none` и `::-webkit-scrollbar { display: none }`), низ списка плавно растворяется: `mask-image: linear-gradient(to bottom, #000 calc(100% - 28px), transparent)`.
- **Иерархия:**
  - H2 — номер «1», «2»… (моноширинный 11px), текст 13px/500;
  - H3 — номер «1.1», «1.2», строка сдвинута вправо, слева тонкая вертикальная линия: `margin-left: 18px; padding-left: 6px; border-left: 1px solid var(--line)`;
  - H4 — без номера, ещё глубже (`padding-left: 20px`), 12px;
  - H5–H6 в оглавление не включать.
- **Длинные названия** — максимум 2 строки, дальше многоточие (`-webkit-line-clamp: 2`). Полный текст в `title`.
- **Раскрыт только раздел, который сейчас читают.** У остальных H2 справа число подразделов и стрелка; клик по ней раскрывает раздел. В шапке оглавления кнопка «Expand all» / «Collapse».
- **Текущий пункт** подсвечен фоном `--accent-soft` и цветом `--accent-text`. Его раздел H2 — жирным, номер раздела — цветом акцента.
- **Текущий пункт определяется по прокрутке** (IntersectionObserver по заголовкам). Если он ушёл за край списка, прокрутить список так, чтобы он был виден.
- **Внизу** ссылка «Back to top».
- **В тексте заметки:** h2 — 24px с линией снизу, h3 — 20px, h4 — Onest 15px/600.
- **Мобильный:** тот же список внутри раскрывающегося блока «On this page» над текстом — с той же иерархией и тем же раскрытием только текущего раздела.
