# Padmark — правки по дизайну

Делать по порядку. После пунктов 1–2 сделать скриншоты трёх форм (заметка, ссылка, файл) во всех трёх темах и показать до того, как браться за остальное.

Бэкенд не трогать, кроме того, что прямо сказано ниже.

## 1. Баланс форм — главное

Проблема: у ссылки и файла правая панель намного выше левой карточки, форма выглядит перекошенной.

Правило для всех форм — создание и редактирование заметки, ссылки, файла:

- **Колонки одной высоты.** Контейнер `display: flex; flex-wrap: wrap; gap: 20px; align-items: stretch`. Левая карточка `flex: 999 1 560px`, панель `flex: 1 1 300px`.
- **Левая карточка** — `display: flex; flex-direction: column`. Растягиваемая часть `flex: 1`, нижняя строка карточки прижата к низу.
- **Панель** — `display: flex; flex-direction: column`. Блок с главной кнопкой `margin-top: auto`, над ним разделитель. Кнопка стоит на одной линии с низом левой карточки.

Что внутри левой карточки (смотреть `screens/Link.html`, `screens/FileUp.html`, `screens/Main.html`):

- **Ссылка.**
  - Поле адреса — textarea на 3 строки: моноширинный 13px, перенос по символам, чтобы длинный URL был виден целиком. Под ним slug.
  - Ниже, на всю оставшуюся высоту, блок «Preview» на фоне `--sunken`, обновляется сразу:
    - короткая ссылка — моноширинный 20px, окончание цветом акцента;
    - строка про режим: «shows the destination first, then continues to» или «redirects to»;
    - домен крупно и полный адрес мелко;
    - чипы выбранных настроек: доступ, срок, «Burns after the first click», если включено.
- **Файл.** Зона загрузки `flex: 1`, минимум 220px. Выбранный файл показывается внутри зоны по центру: иконка, имя, размер, кнопки «Replace» и «Remove». Ниже slug, внизу строка «Your file link».
- **Заметка.** Редактор `flex: 1`, минимум 380px.
- **Экраны редактирования** ссылки и файла устроены так же. У ссылки тоже блок превью; у файла вместо зоны загрузки — тот же блок с файлом, без Replace и Remove, с пометкой «Name and content are fixed».

## 2. Правая панель

- **Доступ** — компактный список в одной рамке (скругление 10px) вместо трёх больших карточек.
  - Строка ~48px: radio, название 13px/600, описание 12px приглушённым цветом. Выбранная строка — фон `--accent-soft`.
  - Заголовок: «Who can read», «Who can follow» или «Who can download».
- **Если пользователь не вошёл,** Login required и Owner only не прятать, а показывать неактивными со строкой «Sign in to restrict access» (ссылка на вход). Сейчас остаётся радиокнопка из одного пункта.
- **Переключатели** — без цветных квадратиков с иконками: название 13px/600, подпись 12px, сам переключатель 40×24.
- **Ширина панели** не меньше 300px, чтобы названия помещались в одну строку.
- **Сгорание называется одинаково:** «Burn after reading», «Burn after first click», «Burn after first download». Сейчас у файла «Delete after first download».
- **Срок жизни ссылки:** готовые варианты плюс «Custom…». Для своего срока — число и единица (minutes / hours / days), а не секунды. Перевод в секунды — на фронтенде, API не менять.
- **Edit code** — поле с кнопкой генерации и подписью «Lets you edit or delete the {note|link|file} later».
- **На экранах редактирования:**
  - «Delete» отделить от «Save»: ниже, после разделителя, с подтверждением. У заметки тоже нужна «Delete note».
  - Неизменяемое — slug, сгорание ссылки после создания — показывать текстом со значком замка, а не полем ввода или выключенным переключателем.

## 3. Шапка и футер — одинаковые на всех страницах

- **Десктоп:** логотип · вкладки Note / Short link / File · API · GitHub · тема (три кнопки) · «Sign in» или аватар.
  - Вкладка File есть на всех страницах (если загрузка только после входа — вкладка ведёт на вход).
  - Админка и смена пароля — та же шапка, а не отдельный вариант.
  - На страницах просмотра вместо вкладок кнопка «New», как сейчас.
- **Мобильный:** справа всегда тема и меню. После входа вместо иконки меню — аватар, открывающий то же меню. «+» на страницах просмотра оставить.
- **Футер:** одна подпись везде — «Padmark — notes, links & files».

## 4. Тексты и мелочи

- **404:** «Paste not found» → «Not found»; «Create new paste» → «New note».
- **Reveal:** «One-time document» → «One-time note».
- **Число просмотров:** «1 views» → «1 view».
- **После публикации** одинаковый набор ссылок на всех трёх экранах: «Write another note · Shorten a link · Upload a file».
- **Заголовки в тексте заметки:** h1 из Markdown 24px, h2 20px — меньше названия заметки, чтобы не было двух одинаковых заголовков подряд.
- **Оглавление «On this page»** на десктопе прилипает к верху при прокрутке (`position: sticky; top: 24px`).
- **Плашка edit code в тёмных темах:** вместо сплошной коричневой заливки — рамка 1px `--warn` и лёгкий фон.

## 5. Страница ссылки в режиме «show destination first»

- Главная кнопка «Continue to {домен} →».
- Если ссылка сгорает после первого клика — предупреждение, как на reveal: «This link works once. Continuing uses it up.»

## 6. Мобильные

- **Edit code в одну строку:** без разрядки между буквами, кнопки Hide и Copy не должны переносить код.
- **Опасные кнопки:** «Delete file», «Delete link» и «Sign out» не ставить вплотную под главной кнопкой.
- **Админка:** вкладка показывает только свой раздел. Password — раздел внутри админки, с её шапкой.
- **Просмотр заметки:** без карточки с рамкой — текст прямо на фоне, отступ 16px. Строка «On this page» закреплена сверху при прокрутке.
- **Вход:** убрать «Back to Padmark», она разрывается на две строки.
- **Сводка в Settings у ссылки** показывает значение («expires in 2 min»), а не режим («custom, in seconds»).

## 7. Первый запуск (Create admin account)

- **Токен:** в поле — «Bootstrap token», пояснение «Value of PADMARK_BOOTSTRAP_TOKEN on the server» под полем. Справа в поле отступ под иконку глаза — сейчас текст уходит под неё.
- **Требования к паролю** — под полем (лучше списком, где каждое требование отмечается при вводе), не в placeholder.
- **Код из приложения.** Если после создания есть шаг подключения кода, сказать об этом в подзаголовке: «Step 1 of 2 — next you'll connect an authenticator app».
- **«Sign in» в шапке** скрыть, пока админ не создан.
