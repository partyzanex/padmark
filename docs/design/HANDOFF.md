# Padmark — редизайн, передача в разработку

Задача: перенести этот дизайн в реальный код Padmark. Макеты — ориентир по вёрстке и стилям, а не готовые шаблоны.

## Что в папке
- `tokens.css` — все цвета трёх тем как CSS-переменные: светлая `.pm`, средняя `.pm.dim`, тёмная `.pm.dark`. Начать с него.
- `screens/*.html` — макеты экранов в светлой теме. Другие темы отличаются только классом на корневом элементе.

Файлы макетов написаны для редактора макетов: `{{имя}}` — подстановки, `<sc-if>` / `<sc-for>` — условия и циклы, блок `<script type="text/x-dc">` в конце — демо-логика. В продукт это не переносить; брать разметку и inline-стили.

## Экраны
| Файл | Экран |
|---|---|
| Main | Редактор заметки: заголовок, URL, Write / Split / Preview, справа панель публикации |
| Link | Короткая ссылка: тот же каркас, слева карточка URL + slug, справа настройки |
| Published-light | После публикации: ссылка, копирование, edit code |
| Note / NoteNoToc | Просмотр заметки с колонкой «On this page» слева и без неё (на всю ширину) |
| NoteLong | Заметка с заголовком на 2–3 строки |
| Admin-light | Админка: пользователи, инвайт, API-ключи |
| SignIn-light | Вход: логин, пароль, TOTP |
| Mobile* | Те же экраны на 390px; настройки публикации — нижняя панель (MobileSheet) |

## Решения, которые нужно сохранить
- Шрифты: Onest — интерфейс, JetBrains Mono — slug, ключи, метаданные, подписи; Source Serif 4 — логотип, заголовки, текст заметки.
- Размеры шрифта только из шкалы 11 / 12 / 13 / 14 / 15 / 17 / 20 / 24 / 28 / 32. На мобильных поля ввода 16px.
- Десктоп: главные кнопки 44px, поля 36–40px, скругление карточек 12–14px, полей 9–10px, ширина страницы 1200px (заметка 1120px).
- Мобильный: шапка 52px, кнопки 48px, зоны нажатия не меньше 44px.
- Доступ: Public, Login required, Owner only — и у заметки, и у ссылки.
- У заметки и у ссылки есть поле Edit code («Generated if blank»).
- «Contents sidebar» — настройка заметки при создании; на мобильном оглавление — выпадающий список над текстом.
- Футер прижат к низу экрана.
- Переключатель темы: три состояния, на мобильном — одна кнопка по кругу.

## Придумано в макете, сверить с бэкендом
- Сроки жизни ссылки (1 час, 1 / 7 / 30 дней) и задержки сжигания (сразу, 5 минут, 1 час).
- «Показывается один раз» для edit code и нового API-ключа.
- Экран «Published» как отдельный шаг после публикации.
- `[your-host]` — заглушка домена; тексты и данные в макетах выдуманы.

## Не сделано
- Меню под иконкой на мобильном не нарисовано.
- Панель публикации в редакторе длинная; возможно, часть настроек стоит свернуть.
