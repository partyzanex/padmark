# Padmark — дизайн, итерация 2

Первая версия редизайна уже в коде. Эта папка — правки поверх неё.

- **`TASKS.md`** — что исправить, по порядку. Начинать с него.
- **`tokens.css`** — цвета трёх тем: светлая `.pm`, средняя `.pm.dim` (обновлена: фон #26272F, карточки #2F3039), тёмная `.pm.dark`. Сверить со своими переменными и заменить отличающиеся значения.
- **`screens/*.html`** — макеты в светлой теме. Остальные темы отличаются только классом на корневом элементе.

Макеты сделаны в формате редактора макетов: `{{имя}}` — подстановки, `<sc-if>` / `<sc-for>` — условия и циклы, блок `<script type="text/x-dc">` в конце — демо-логика. В продукт это не переносить: брать разметку, inline-стили и размеры.

## Система
- **Шрифты:** Onest — интерфейс; JetBrains Mono — slug, ключи, коды, метаданные, подписи-лейблы; Source Serif 4 — логотип, название и текст заметки.
- **Размеры шрифта** только из шкалы 11 / 12 / 13 / 14 / 15 / 17 / 20 / 24 / 28 / 32. На мобильных поля ввода 16px.
- **Десктоп:** главная кнопка 40–44px, поля 36px, скругление карточек 12px, полей 9px, ширина страницы 1200px.
- **Мобильный:** шапка 52px, кнопки 48px, зоны нажатия не меньше 44px.
