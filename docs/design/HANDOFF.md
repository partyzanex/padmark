# Padmark — дизайн, итерация 3

Первая версия редизайна уже в коде. Эта папка — все правки поверх неё. В неё вошёл и предыдущий пакет: если какие-то пункты уже сделаны, их просто пропустить.

- **`TASKS.md`** — что сделать, по порядку. Начинать с него.
- **`tokens.css`** — цвета трёх тем: светлая `.pm`, средняя `.pm.dim`, тёмная `.pm.dark`.
- **`screens/*.html`** — макеты в светлой теме. Остальные темы отличаются только классом на корневом элементе.
- **`assets/`** — пример картинки для макетов просмотра изображения: большая 3200×2000 и маленькая 640×400.

Макеты сделаны в формате редактора макетов: `{{имя}}` — подстановки, `<sc-if>` / `<sc-for>` — условия и циклы, блок `<script type="text/x-dc">` в конце — демо-логика. В продукт это не переносить: брать разметку, inline-стили, размеры и поведение, описанное в демо-логике.

## Система
- **Шрифты:** Onest — интерфейс; JetBrains Mono — slug, ключи, коды, метаданные, подписи-лейблы; Source Serif 4 — логотип, названия и текст заметки.
- **Размеры шрифта** только из шкалы 11 / 12 / 13 / 14 / 15 / 17 / 20 / 24 / 28 / 32. На мобильных поля ввода 16px.
- **Десктоп:** главная кнопка 40–44px, поля 36px, скругление карточек 12px, полей 9px, ширина страницы 1200px.
- **Мобильный:** шапка 52px, кнопки 48px, зоны нажатия не меньше 44px.
